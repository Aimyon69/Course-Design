# 质量门控 LMF 阶段工作总结

日期：2026-10-30 ｜ 数据集：CH-SIMS（train 1368 / valid 456 / test 457）
环境：WSL conda `host`（torch 2.11.0+cu130 / transformers 5.20.2 / CUDA）

> 详细方法、逐条件结果和复现命令见 `doc/实验记录_质量门控LMF.md`。
> 本文只总结这一阶段做了什么、得到什么结论、哪些结论不能 overclaim。

## 1. 目标

在标准三模态 LMF（Liu et al., ACL 2018）上加入可退化标量门控：

```
g_m = present_m · sigmoid(MLP_m(q_m)) ∈ [0, 1]
p'_m = 1 + g_m · (p_m - 1)
h = Σ_r w_r · ∏_m p'_{m,r} + b
```

- `g_m=0` 时该路成为逐元素乘法的单位元，等价于移除该模态；
- `g_m=1` 时退化为原始 LMF；
- 质量向量：文本 `[1]`（另用 `present` 标记缺失）、视觉 `[face_frac]`、
  语音 `[speech_frac, snr_db/60]`。

改进主张：某一模态质量下降时，改进 LMF 的 Macro-F1 退化幅度小于标准 LMF；
不预设干净输入上的提升。

## 2. 实验设置

- 三路冻结特征：BERT [CLS] 768 / CLIP 512 / Chinese-Wav2Vec2 768。
- 四个对照，同一划分、同一编码器、同一训练预算：

| 方法 | 结构 | 训练数据 |
|---|---|---|
| `lmf` | 标准 LMF | 干净 |
| `lmf_pert` | 标准 LMF | 干净 + 扰动增强 |
| `lmf_gate` | LMF + 质量门控 | 干净 |
| `lmf_gate_pert` | LMF + 质量门控 | 干净 + 扰动增强 |

- 扰动在原始输入上施加，再走冻结编码器：
  - 语音：白噪声 SNR 10 / 5 dB（评测另加 0 dB）；
  - 视觉：人脸框内灰度矩形遮挡 20% / 30% / 40%（评测另加 60%）；
  - 文本：15% 汉字随机替换（评测 10% / 20% / 30%）。
- 训练/评测扰动使用不同随机种子，避免记住具体噪声实现。
- 训练增强：每个模态独立 `p_miss=0.08`、`p_pert=0.40`。
- Adam lr 1e-3 / wd 1e-4，batch 128，类别加权交叉熵，
  按 clean valid Macro-F1 早停（patience 30，最多 200 epoch），seed 42 / 1 / 7。

> 协议修正：`patience=10` 会在扰动训练收敛前停止。`lmf_gate_pert` 的 valid
> 曲线在第 25 epoch 左右才到最优，patience 10 下 test 仅 0.5456，放宽到 30 后
> seed 42 为 0.5953。四个对照统一使用 patience 30，未按 test 调参。

## 3. 主要结果

test Macro-F1，三个 seed 的均值 ± 总体标准差；“组合退化”= 语音 SNR 5 dB +
视觉遮挡 40%。

| 方法 | 干净 | 视觉 occ60 | 组合退化 | 文本 corr30 | 语音 snr0 |
|---|---|---|---|---|---|
| LMF | 0.6032±0.0174 | 0.5281±0.0206 | 0.5282±0.0374 | 0.5183±0.0187 | 0.5906±0.0180 |
| LMF + 扰动训练 | 0.5273±0.0049 | 0.5335±0.0005 | 0.5223±0.0033 | 0.4397±0.0174 | 0.5266±0.0020 |
| LMF + 质量门控 | 0.6140±0.0147 | 0.5257±0.0088 | 0.5317±0.0127 | 0.5200±0.0253 | 0.6114±0.0033 |
| LMF + 门控 + 扰动 | 0.5834±0.0143 | **0.5731±0.0083** | **0.5748±0.0112** | 0.4663±0.0233 | 0.5745±0.0126 |
| 拼接 + MLP（干净训练参考） | 0.6673 | 0.4967 | 0.4760 | 0.5692 | 0.6479 |

分组平均：

| 方法 | 干净 | 语音退化 | 视觉退化 | 文本退化 | 单模态缺失 | 双模态缺失 | 全部退化 |
|---|---|---|---|---|---|---|---|
| LMF | 0.6032 | 0.5927 | 0.5396 | 0.5473 | 0.5140 | 0.3921 | 0.5178 |

| 拼接 + MLP | 0.6673 | 0.6399 | 0.5190 | 0.5897 | 0.5918 | 0.4612 | 0.5551 |

## 4. 改进主张的适用条件

相对 LMF 的同 seed 配对差（负值表示门控+扰动更低）：

| 条件 | 绝对 F1 差 | 退化幅度差（百分点，正=退化更小） | 结论 |
|---|---|---|---|
| vision_occ20 | +0.0266±0.0109 | +7.74±1.52 | 成立 |
| vision_occ40 | +0.0373±0.0217 | +9.47±3.13 | 成立 |
| vision_occ60 | +0.0450±0.0144 | +10.74±2.15 | 成立，三个 seed 均正 |
| audio_snr0 | -0.0161±0.0083 | +0.60±1.26 | 绝对精度更低，退化幅度优势在噪声内 |
| text_corr30 | -0.0520±0.0083 | -6.03±1.52 | 不成立，更差 |
| missing_text | +0.0555±0.0809 | +11.60±13.31 | 方向性成立，方差很大 |
| missing_audio | -0.0270±0.0020 | -1.27±0.55 | 稳定更差 |
| audio_snr5+vision_occ40 | +0.0466±0.0262 | +11.04±3.83 | 成立 |

结论：

- **视觉退化：稳定成立。** occ60 绝对 F1 +0.045，退化幅度从 7.5 个百分点
  降到约 1.0 个百分点；三个 seed 的配对差为 +0.042 / +0.029 / +0.064。
- **组合退化：成立。** +0.047，退化幅度少 11 个百分点，是“多模态同时受扰”
  场景下最有说服力的结果。
- **语音退化：只有可忽略的退化幅度优势，绝对精度更低。** 0 dB 白噪声下
  标准 LMF 只掉 1.8%，Wav2Vec2 特征对加噪不敏感，门控没有发挥空间。
- **文本退化：不成立且更差。** 文本质量输入恒为 1，门控无法区分替换比例；
  15% 扰动训练没有迁移到 30%，还拉低了干净文本精度。
- **缺失：部分成立。** `present` 掩码解决了缺失时乘积不稳定的问题，
  但只稳定超过 LMF 的缺失训练；缺失 audio 反而稳定更差 0.027。
- 与拼接参考相比：门控+扰动只在视觉退化和组合退化上超过拼接
  （occ60 0.5731 vs 0.4967；组合 0.5748 vs 0.4760），
  干净、语音、文本、缺失仍明显落后。

## 5. 关键负结果：门控没有学会按质量降权

- 门控值几乎是常数：视觉 0.840（clean）→ 0.839（occ60），
  语音 0.857 → 0.860（snr0），文本恒为 0.902。
- 逐样本扫描最优视觉门控 `g*`（固定其他两路，在 [0,1] 上取 21 个点）：
  - `g*` 中位数为 1.0，均值 0.63；约 30%–37% 的样本偏好 `g*<0.5`；
  - `g*` 与 `face_frac` 的相关为 **-0.14**（occ60），
    与“特征到干净质心的余弦”的相关为 **-0.07**；
  - 相对训练值 `g≈0.84`，逐样本最优门控带来的平均损失下降只有 **0.024**，
    仅 24% 的样本下降超过 0.01。
- 冷启动检查：末层零初始化会让第一层第一步没有梯度。改用 `--gate-init 0.5`
  后门控末层权重从 0.19 增到 1.07，但 valid Macro-F1 从 0.5432 降到 0.5198，
  且遮挡下门控略升不降。因此门控不随质量变化不是初始化造成的。
- **收益来源应归因于**：`present` 掩码带来的缺失感知乘积结构、模态 dropout、
  以及在受扰特征上的训练；**不是**逐样本质量自适应。

## 6. 机制消融

| 配置 | 干净 | 视觉 occ60 | 文本 corr30 | 缺失 text | 缺失 audio |
|---|---|---|---|---|---|
| LMF（干净训练） | 0.6032 | 0.5281 | 0.5183 | 0.4006 | 0.5960 |
| + 扰动训练（无门控） | 0.5273 | 0.5335 | 0.4397 | 0.4010 | 0.5266 |
| + 门控（干净训练） | 0.6140 | 0.5257 | 0.5200 | 0.2502 | 0.4810 |
| + 门控 + 全扰动（完整方案） | 0.5834 | 0.5731 | 0.4663 | 0.4561 | 0.5691 |
| + 门控 + 仅缺失增强 | 0.5357 | 0.5433 | 0.4402 | 0.3514 | 0.5376 |
| + 门控 + 仅视觉扰动 | 0.5764 | 0.5780 | 0.4921 | 0.4101 | 0.5703 |

- 标准 LMF 做扰动训练反而最差：没有 `present` 掩码，缺失/受扰特征进入
  逐元素乘积后无法退化为单位元。
- 只做门控、不做缺失训练，缺失条件崩溃（0.3491 / 0.2618），说明门控结构
  不能替代训练时见过缺失。
- 仅缺失增强已能在 occ60 达到 0.5433，说明视觉鲁棒性有一部分来自
  “学会用另外两路预测”；完整方案再提到 0.5731，并改善缺失 text。

## 7. 结论与下一步

1. 可退化门控 LMF 在**视觉退化**和**音视频组合退化**下确实比标准 LMF 更鲁棒，
   这是可复现的改进；但干净输入低 0.020，文本/语音退化下更差。
2. 改进不是“质量门控学会了降权”带来的；门控值近似常数，逐样本最优门控
   与质量信号不相关。论文/答辩中应把它写成“缺失感知 + 受扰训练的鲁棒 LMF”，
   不能写成“质量自适应门控有效”。
3. 拼接 + MLP 在干净、语音、文本、缺失上仍明显更强。如果最终系统更看重
   干净精度，应优先拼接，或把 `present` 掩码/模态 dropout 加到拼接融合上。
4. 下一步优先级：
   - 在拼接融合上加入 `present` 掩码和模态 dropout，检验能否同时保住
     干净精度和缺失鲁棒性；
   - 接入 ASR 后，用 ASR 置信度/语言模型分数重做文本质量输入；
   - 用更真实的噪声（混响、多人说话、远场）检验语音门控；
   - 自采数据上复测，并记录实时链路的刷新间隔与端到端延迟。
