# 汇报要点

---

数据集选取：CH-SIMS

​	选取原因：CH-SIMS是中文三模态情感分析基准数据集，每条样本同时包含视频、音频、人工转录文本，并且提供独立单模态标注，很适合我	们研究多模态融合，以及模态质量评估（门控模块）。区别于英文MOSI/MOSEI，它适配中文对话场景。

ASR：FunASR SenseVoiceSmall

视觉特征提取模块：CLIP - ViT - B / 32

​	输入：预处理后的人脸RGB图像 [3,224,224]

​	使用方式：加载预训练权重，冻结全部参数；取[CLS]向量作为单帧视觉特征

​	单帧输出特征维度：d_v = 512

​	时序处理：一段视频采样T帧，得到序列[T, 512]；再做全局池化得到固定维度向量，送入LMF

其他两模态特征提取器（暂定）：

​	wav音频 → 16kHz重采样 → Wav2Vec2提取音频时序特征 → 全局池化得到单向量

​	文本 → tokenizer编码 → bert-base-chinese前向，取CLS向量
