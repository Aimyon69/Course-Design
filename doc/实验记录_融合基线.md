## 0. 输入与对齐

三路冻结片段级特征沿用前三个阶段的缓存：

| 模态 | 编码器 | 维度 | 缓存 |
|---|---|---|---|
| 文本 | bert-base-chinese [CLS] | 768 | `outputs/features/text_cls.pt` |
| 视觉 | CLIP-ViT-B/32 人脸帧均值 | 512 | `outputs/features/vis_cls.pt` |
| 语音 | chinese-wav2vec2-base 时序均值 | 768 | `outputs/features/audio_cls.pt` |

- 2281 条，官方划分 train 1368 / valid 456 / test 457。
- `code/fusion/fusion_data.py` 按 `sample_id` 严格对齐三路，并断言三路标签逐条一致；
  不依赖各缓存内部行序。
- 每个模态只在训练集上估计 z-score 均值/方差，再应用于 valid/test。
- 监督标签仍为多模态总标签 `label_M` 的三类离散化，与单模态实验一致。

## 1. 方法

### 1.1 拼接 + MLP（concat）

- 三路标准化特征直接拼接为 2048 维，接 `2048 → 64 → 3` 的 MLP，dropout 0.3。
- 参数量 **131,331**。
- 隐层取 64 而不是 256：一是与 LMF 的约 13 万参数匹配，避免把差异归因于分类头容量；
  二是 valid Macro-F1 更高（0.6043 vs 0.5965）。作为参考，h=256 的 test Macro-F1 为 0.6469。

### 1.2 LMF（Low-rank Multimodal Fusion）

按 Liu et al., ACL 2018 的官方实现（`Justin1904/Low-rank-Multimodal-Fusion`，并与
MMSA `singleTask/LMF.py` 对照）：

1. 每路先过预融合子网 `SubNet`：`BatchNorm1d → Dropout(0.2) → Linear+ReLU ×3`；
2. 在每路子网输出末尾拼接常数 1（ones-appending），保留单模态、双模态、三模态交互；
3. 模态专属低秩因子 `Factor_m ∈ R^{rank × (hidden_m+1) × n_classes}`，
   `z_m = Factor_m^T [1; h_m]`；
4. 三路 `z_m` 逐元素相乘，按 rank 用可学习权重加权求和并加融合偏置，直接输出三类 logits：

   ```
   h = Σ_r w_r · ∏_m z_{m,r} + b
   ```

5. 因子与融合权重 `xavier_normal` 初始化，融合偏置置零。

实现细节：

| 项目 | 取值 |
|---|---|
| rank | 4 |
| 预融合 hidden（text / vision / audio） | 64 / 16 / 64 |
| dropout | 0.2 |
| 输出 | 3 类 logits（不再接额外分类层） |
| 参数量 | **129,691** |

- MMSA 的 CH-SIMS（SIMS）配置是 text 64 / audio 16 / video 64，但那是针对
  openSMILE 33 维音频和 709 维视觉特征。本项目使用 CLIP 512 维与 Wav2Vec2 768 维，
  直接套用会不稳定；hidden 分配在 valid 上比较后取 text 64 / vision 16 / audio 64。
- 文本输入是池化后的 [CLS] 向量而非词序列，因此文本子网与音视频一样用 MLP；
  官方实现中文本分支为 LSTM，这是本项目“片段级特征”口径下的必要适配。
- LMF 对 hidden 分配和初始化较敏感：部分配置（如 vision 64 / audio 16）在 seed 42 下
  会塌缩到多数类（valid Macro-F1 = 0.2348）。表中配置在 seed 42 / 1 / 7 下均稳定。

### 1.3 统一训练协议

两种方法除结构外完全一致：

- 类别加权交叉熵（train 权重 Negative 0.615 / Neutral 2.203 / Positive 1.088）；
- Adam，lr 1e-3，weight decay 1e-4，batch 128；
- 按 valid Macro-F1 早停，patience 10，最多 100 epoch，seed 42；
- 同一三路编码器、同一划分、同一标准化统计量。

## 3. 分析

- **融合有效**：拼接融合的 Macro-F1 0.6673、Accuracy 0.7462，比最好的单模态
  （文本 0.5921 / 0.6608）分别高 **+0.075 / +0.085**；三路信息确实互补。
- **本轮 LMF 低于拼接**：LMF 的 Macro-F1 0.5831，与文本单模态（0.5921）接近，
  比拼接低 0.084。这不是“LMF 一定更差”的结论，而是本数据规模下的复现结果：
  训练集仅 1368 条，三路逐元素乘积的低秩融合参数很少、优化更敏感；
  hidden/初始化稍变就可能塌缩。拼接头的加性结构在此规模下更容易训练。
- 中性类仍是瓶颈：拼接 Neu-F1 0.4179、LMF 0.3231。中性训练样本仅 207 条，
  test 仅 69 条，两类方法都主要把中性误判为负/正。
- **种子稳定性**：拼接 seed 42/1/7 的 test Macro-F1 为 0.6673 / 0.6567 / 0.6297；
  LMF 为 0.5831 / 0.6169 / 0.6101。单 seed 主结果之上，拼接仍稳定领先约 0.05。
- **协议敏感性**：若改用 MMSA 的 CH-SIMS LMF 训练超参（lr 2e-3、factor lr 5e-4、
  wd 5e-3、batch 64），LMF test Macro-F1 = 0.6026；同样设置下拼接 h=64 为 0.6557，
  结论不变。主表保留统一协议，便于与后续门控 LMF 做控制变量对比。
- 本阶段没有加入质量门控、模态缺失或噪声扰动；LMF 0.5831 是下一阶段改进方案的
  **直接对照基线**。
