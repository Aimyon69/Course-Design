# 本周进度汇报（截至 2026-10-22）

## 一、数据集与统一数据接口

- 已确认 `label.csv`（CH-SIMS 标注文件）可用：共 **2281** 条，官方划分 train 1368 / valid 456 / test 457，含人工转写文本、四路连续标签和三类标注。
- **核实并修正了一个关键问题**：文件中四个数值列的顺序是 `label（多模态总标签）、label_T、label_A、label_V`（多模态标签在第一位），而非直觉上的 T/A/V/M。依据 MMSA-FET 官方解析代码逐列比对确认，并与社区已知示例行互证。
- 三类标签规则确定并写入代码自检：`annotation = 总标签按阈值 0 离散化`（< 0 负面 / = 0 中性 / > 0 正面），2281 条全部一致，之后不再改动。另发现 499 条单模态标签与总标签符号冲突（反讽场景），属 CH-SIMS 设计特性，已记录避免误用。
- 产出统一数据模块 `code/common/chsims.py`，后续语音、视觉模态与所有融合实验共用同一接口和同一划分。

## 二、实验环境

- 运行环境定为 WSL conda `host`（torch 2.11.0+cu130，CUDA 可用），已补齐 transformers 5.20.2 / scikit-learn / pandas。

## 三、文本模态（本周主要交付）

- **特征链路打通**：按既定方案，文本 → tokenizer 编码 → **bert-base-chinese（权重全部冻结）** → 取 [CLS] 向量，维度 768。2281 条特征已提取并缓存（`outputs/features/text_cls.pt`），训练与后续演示共用同一条链路。
- **单模态基线完成**：冻结特征 + 768→256→3 MLP 分类头，类别加权损失，按验证集 Macro-F1 早停。
- **测试集结果（457 条）**：

| 模型 | Accuracy | Macro-F1 | 负 F1 | 中 F1 | 正 F1 |
|---|---|---|---|---|---|
| MLP 头 | **0.6608** | **0.5921** | 0.747 | 0.351 | 0.678 |
| LogisticRegression（对照） | 0.5667 | 0.4997 | 0.653 | 0.282 | 0.565 |

  混淆矩阵、逐类 F1 与完整配置已存档（`outputs/results/text_baseline/`）。

## 四、问题与观察

- 中性类识别最弱（F1 0.35），原因是中性训练样本仅 207 条且语义边界模糊，后续可在门控与融合阶段再观察。
- 当前结果为"冻结骨干"口径，与方案约定一致；若后续允许微调编码器末层，文本单模态仍有上行空间。
