# 文本模态实验记录（第 1 阶段）

日期：2026-10-22 ｜ 环境：WSL conda `host`（torch 2.11.0+cu130 / transformers 5.20.2 / CUDA 可用）

## 1. 数据接口（code/common/chsims.py）

- 数据：`label.csv`，共 **2281** 条（train 1368 / valid 456 / test 457），采用文件自带官方划分。
- 列语义已按 MMSA-FET 官方解析代码确认：`video_id, clip_id, text, label, label_T, label_A, label_V, annotation, mode`。
  四个数值列的顺序是 **label（多模态总标签 label_M）、label_T、label_A、label_V**（多模态标签在第一位）。
- **三类标签规则（写入代码并每次运行时自检）**：`annotation = label_M 按阈值 0 离散化`——< 0 负面（Negative）、= 0 中性（Neutral）、> 0 正面（Positive）。已验证 2281 条全部一致。
- 注意：第 4–6 列（T/A/V 单模态标签）与总标签存在 499 条符号冲突（反讽等场景），属 CH-SIMS 设计特性，**不得**用单模态标签替代总标签做三分类监督。
- 标签分布（负/中/正）：train 742/207/419，valid 248/69/139，test 248/69/140，类别不均衡（中性最少）。

## 2. 文本特征提取（code/text/extract_text_features.py）

- 按进度汇报约定：tokenizer 编码 → **bert-base-chinese 前向，取 [CLS] 向量**，d = 768。
- 模型权重冻结，仅推理；max_len = 64（数据最长转写 47 字符）。
- 缓存：`outputs/features/text_cls.pt`（{train, valid, test} × {sample_id, feat[768], label3, label_m}），后续融合实验直接复用。

## 3. 单模态基线（code/text/train_text_baseline.py）

- 分类头：768→256→3 的 MLP（dropout 0.3），训练集标准化（均值/方差取自 train），
  类别加权交叉熵（权重 ∝ 1/类别频率），Adam lr 1e-3、wd 1e-4，按 valid Macro-F1 早停（patience 10），seed 42。
- 另附 sklearn LogisticRegression（class_weight='balanced'）作对照。

### 测试集结果（457 条）

| 模型 | Accuracy | Macro-F1 | Neg-F1 | Neu-F1 | Pos-F1 |
|---|---|---|---|---|---|
| MLP 头 | **0.6608** | **0.5921** | 0.7468 | 0.3514 | 0.6781 |
| LogisticRegression | 0.5667 | 0.4997 | 0.6527 | 0.2817 | 0.5646 |

- 观察：中性类最难（Neu-F1 仅 0.35），主因是中性训练样本仅 207 条且语义边界模糊；负/正两类已可用。
- 说明：当前为**冻结骨干**的口径，与进度汇报一致；若后续允许微调 bert 末层，文本单模态仍有上行空间（需与方案"先冻结"的约定对齐后再动）。
