# 质量门控 LMF 实验记录（第 5 阶段）

日期：2026-10-30 ｜ 环境：WSL conda `host`（torch 2.11.0+cu130 / transformers 5.20.2 / CUDA）

## 0. 目标与对照

方案第 3 节的改进点：在标准 LMF 的逐模态低秩投影上加入可退化标量门控，
让模型在某一模态质量下降或缺失时**逐样本**减弱该路，而不是全局固定权重。
改进主张只针对受扰条件——干净输入上的精度提升不预设。

四个对照使用完全相同的官方划分、三路冻结特征、LMF 结构与训练预算：

| 方法 | 结构 | 训练数据 |
|---|---|---|
| `lmf` | 标准 LMF | 干净 |
| `lmf_pert` | 标准 LMF | 干净 + 扰动增强 |
| `lmf_gate` | LMF + 质量门控 | 干净 |
| `lmf_gate_pert` | LMF + 质量门控 | 干净 + 扰动增强 |

- 基础结构与第 4 阶段一致：rank 4，预融合 hidden text 64 / vision 16 / audio 64，
  dropout 0.2，直接输出 3 类 logits。
- 训练协议一致：类别加权交叉熵，Adam lr 1e-3 / wd 1e-4，batch 128，
  按 clean valid Macro-F1 早停（patience 30，最多 200 epoch），seed 42 / 1 / 7。
- patience 从第 4 阶段的 10 放宽到 30：扰动增强让收敛变慢，patience 10 会在
  `lmf_gate_pert` 的 valid 曲线仍在上升时停止（见 3.7 节）。四个对照使用同一
  patience 与最大 epoch，保持同等训练预算；主表报告三个 seed 的均值 ± 总体标准差。
- 门控只增加 83 个参数：129,691 → **129,774**（text 25 / vision 25 / audio 33）。
- 另把第 4 阶段干净训练好的拼接 + MLP（131,331 参数）在同样的受扰测试集上
  作为参考，回答“三路拼接本身是否已经足够鲁棒”。

## 1. 受扰数据与质量信号

### 1.1 原始输入扰动

所有扰动都在原始输入上施加，再走与干净特征完全相同的冻结编码器链路
（`code/fusion/build_perturbed_features.py`）：

| 模态 | 扰动 | 训练强度 | 评测强度 | 备注 |
|---|---|---|---|---|
| 语音 | 16 kHz 波形叠加白噪声 | SNR 10 / 5 dB | SNR 10 / 5 / 0 dB | 0 dB 为未见强度 |
| 视觉 | 人脸框内随机位置贴灰度矩形 | 面积 20% / 30% / 40% | 20% / 40% / 60% | 60% 为未见强度；遮挡后重新检测人脸 |
| 文本 | 按比例随机替换汉字 | 15% | 10% / 20% / 30% | 10/20/30% 为未见强度的不同实现 |

- 训练缓存与评测缓存使用不同的随机种子（`seed_offset=0` / `1`）：
  同一段音频的噪声实现、同一视频的遮挡位置、同一文本的替换位置都不同，
  避免“训练时记住具体噪声、评测时原样复现”的泄漏。
- 语音质量在**加噪后的波形**上重新计算；视觉 `face_frac` 在**遮挡后的帧**上
  重新检测；文本重新过 bert-base-chinese。三者与干净缓存同一口径。
- 训练增强对每个样本、每个模态独立采样：以 `p_miss=0.08` 置为缺失；
  否则以 `p_pert=0.40` 从该模态的训练强度中随机取一个条件。
  因此单个样本可能同时有两个模态受扰，也会出现三路都干净或某一路缺失的批次。

### 1.2 质量向量

| 模态 | 门控输入 | 训练/评测/演示是否同口径 |
|---|---|---|
| 文本 | `[1]`，另用 `present` 标记缺失 | 是；离线实验没有 ASR 置信度，文本损坏程度不可观测 |
| 视觉 | `[face_frac]` | 是；由遮挡/原始帧的人脸检测直接得到 |
| 语音 | `[speech_frac, snr_db/60]` | 是；由原始/加噪波形直接估计 |

- 文本门控只能区分“有文本 / 无文本”，不能区分“人工转写 / 含 ASR 错误”。
  这是本阶段的明确局限：文本损坏实验检验的是**扰动训练带来的鲁棒性**，
  而不是文本门控的收益；后者需要 ASR 置信度或语言模型分数，留待 ASR 阶段。
- 模态缺失时 `present=0`，门控被直接置 0；该标记在训练时也能计算，
  不是只在演示时加入的状态码。

## 2. 门控 LMF

对每一路低秩投影 `p_m ∈ R^{rank × n_classes}`：

```
g_m = present_m · sigmoid(MLP_m(q_m))          ∈ [0, 1]
p'_m = 1 + g_m · (p_m - 1)
h = Σ_r w_r · ∏_m p'_{m,r} + b
```

- `g_m=0` 时 `p'_m=1`，该路成为逐元素乘法的单位元，等价于从乘积中移除；
  `g_m=1` 时退化为原始 LMF。
- 每个门控是 `Linear(k, 8) → ReLU → Linear(8, 1)`，末层权重初始化为 0、
  偏置初始化为 2.0（初始 `g≈0.881`），避免训练初期直接关闭模态。
- 常数 1、融合权重、融合偏置、rank 维度和输出映射均与第 4 阶段 LMF 相同。

### 3.3 消融：训练增强与结构各自的贡献

| 配置 | 干净 | 视觉 occ60 | 文本 corr30 | 缺失 text | 缺失 audio |
|---|---|---|---|---|---|
| LMF（干净训练） | 0.6032 | 0.5281 | 0.5183 | 0.4006 | 0.5960 |
| + 扰动训练（无门控） | 0.5273 | 0.5335 | 0.4397 | 0.4010 | 0.5266 |
| + 门控（干净训练） | 0.6140 | 0.5257 | 0.5200 | 0.2502 | 0.4810 |
| + 门控 + 全扰动（完整方案） | 0.5834 | **0.5731** | 0.4663 | **0.4561** | 0.5691 |
| + 门控 + 仅缺失增强 | 0.5357±0.0292 | 0.5433±0.0223 | 0.4402±0.0151 | 0.3514±0.0463 | 0.5376±0.0321 |
| + 门控 + 仅视觉扰动 | 0.5764±0.0297 | 0.5780±0.0154 | 0.4921±0.0171 | 0.4101±0.0906 | 0.5703±0.0258 |

- 只做扰动训练、不做门控（`lmf_pert`）反而最差：标准 LMF 没有 `present` 掩码，
  缺失/受扰特征进入逐元素乘积后无法退化为单位元，干净精度也被拉低到 0.527。
- 只做门控、不做缺失/扰动训练（`lmf_gate`）干净最高，但缺失条件崩溃；
  门控结构本身不能替代训练时见过缺失。
- 仅缺失增强（`p_pert=0`，`p_miss=0.08`）已经能在视觉遮挡下达到 0.5433，
  说明视觉鲁棒性的一部分来自“学会用另外两路预测”，而不是遮挡扰动本身；
  完整方案再把 occ60 提到 0.5731，并明显改善缺失 text（0.3514 → 0.4561）。
- 仅视觉扰动（不做文本/语音扰动）干净 0.5764、occ60 0.5780，与完整方案接近；
  但缺失 text 更低（0.4101），说明文本扰动训练对“文本缺失”有额外帮助，
  代价是文本损坏和干净精度。当前保留完整方案作为主结果。

### 3.4 门控实际学到了什么

`lmf_gate_pert` 在三个 seed 上的门控均值：

| 条件 | text | vision | audio |
|---|---|---|---|
| clean | 0.902 | 0.840 | 0.857 |
| vision_occ40 | 0.902 | 0.839 | 0.857 |
| vision_occ60 | 0.902 | 0.839 | 0.857 |
| audio_snr0 | 0.902 | 0.840 | 0.860 |
| missing_* | 0（被 `present` 置零） | 0/0.840 | 0/0.857 |

- 门控几乎是常数：视觉从 clean 到 occ60 只变 **0.001**，语音从 clean 到 snr0
  只变 **0.003**；文本恒为 0.902（输入恒为 1，只能学到一个常数）。
- 逐样本扫描“最优视觉门控”`g*`（固定其他两路，在 [0,1] 上取 21 个点，
  用真实标签取损失最小者）：
  - `g*` 中位数为 **1.0**，均值 0.63；约 30%–37% 的样本偏好 `g*<0.5`；
  - `g*` 与 `face_frac` 的相关为 **-0.14**（occ60），与“特征到干净质心的余弦”
    的相关为 **-0.07**；即质量越差，最优门控并没有更低；
  - 相对训练值 `g≈0.84`，逐样本最优门控带来的平均损失下降只有 **0.024**，
    仅 24% 的样本下降超过 0.01。
- 结论：在本数据上，**质量信号不能指示某一路是否应该被抑制**。门控保持常数
  是接近最优的选择；视觉鲁棒性提升来自“缺失/遮挡训练 + `present` 掩码”，
  而不是逐样本质量自适应。这是本阶段最重要的负结果，不能把它写成“门控学会了
  按质量降权”。
- 冷启动检查：末层零初始化会让第一层在第一步没有梯度，质量编码器学得很慢。
  改用 `--gate-init 0.5` 的小随机初始化后，门控末层权重从 0.19 增到 1.07，
  但 valid Macro-F1 反而从 0.5432 降到 0.5198，且遮挡下门控略升不降。
  因此主结果保留零初始化；门控不随质量变化不是初始化造成的。

| audio_snr10 | -0.0139±0.0091 | +0.98±0.88 |
| audio_snr5 | -0.0153±0.0105 | +0.73±1.17 |
| audio_snr0 | -0.0161±0.0083 | +0.60±1.26 |
| vision_occ20 | +0.0266±0.0109 | +7.74±1.52 |
| vision_occ40 | +0.0373±0.0217 | +9.47±3.13 |
| vision_occ60 | +0.0450±0.0144 | +10.74±2.15 |
| text_corr10 | -0.0549±0.0141 | -6.20±3.12 |
| text_corr20 | -0.0348±0.0134 | -2.96±2.44 |
| text_corr30 | -0.0520±0.0083 | -6.03±1.52 |
| missing_text | +0.0555±0.0809 | +11.60±13.31 |
| missing_vision | +0.0024±0.0202 | +3.39±3.68 |
| missing_audio | -0.0270±0.0020 | -1.27±0.55 |
| missing_text+vision | +0.0677±0.0466 | +13.09±8.19 |
| missing_text+audio | -0.0325±0.1301 | -3.51±21.50 |
| missing_vision+audio | -0.0044±0.0318 | +2.20±5.76 |
| audio_snr5+vision_occ40 | +0.0466±0.0262 | +11.04±3.83 |

- **视觉退化：主张成立且稳定。** 三个 seed 的 occ60 配对差为
  +0.042 / +0.029 / +0.064，退化幅度少 7.7–10.7 个百分点。
- **组合退化（语音 5 dB + 视觉遮挡 40%）：成立。** 绝对 F1 +0.047，
  退化幅度少 11 个百分点，是“多模态同时受扰”场景下最有说服力的结果。
- **语音退化：不成立（绝对 F1 更低）。** 退化幅度只少 0.6–1.0 个百分点，
  且标准差约 1，不能视为显著；白噪声 0 dB 下 LMF 本身只掉 1.8%，
  Wav2Vec2 特征对加噪很不敏感，质量门控没有可发挥的空间。
- **文本退化：不成立且更差。** 文本质量输入恒为 1，门控无法区分 10%/20%/30%
  的汉字替换；15% 扰动训练没有迁移到 30%，反而把干净文本精度拉低。
  文本门控需要 ASR 置信度/语言模型分数，留到 ASR 阶段。
- **缺失：部分成立。** 缺失 text 和双缺失 text+vision 更好，但方差很大
  （LMF 的 missing_text 本身在 0.34–0.49 间波动）；缺失 audio 稳定地差 0.027。
  `present` 掩码解决了“缺失时乘积不稳定”，但没有稳定超过 LMF 的缺失训练。
- 与拼接参考相比：`lmf_gate_pert` 在 occ60（0.5731 vs 0.4967）和组合退化
  （0.5748 vs 0.4760）上更好，但在干净、语音、文本、缺失上仍明显落后。
  因此本阶段的结论是“更鲁棒的 LMF”，不是“全面超过拼接”。

### 3.6 结论

1. 标准 LMF 在 CH-SIMS 上对视觉遮挡最脆弱（occ60 掉 7.5 个百分点），
   加入 `present` 掩码 + 缺失/扰动训练后，退化幅度降到约 1 个百分点，
   绝对 Macro-F1 提高 0.045；组合退化提高 0.047。这是可复现的改进。
2. 改进不是来自“质量自适应门控”：门控值几乎不随质量变化，逐样本最优门控
   与 `face_frac` 不相关。收益来自缺失感知的乘积结构、模态 dropout 和
   在受扰特征上的训练。
3. 方案原句“在至少一个模态质量下降时退化更小”在**视觉退化**和**组合退化**下
   成立，在**语音退化**下只有可忽略的退化幅度优势、绝对精度更低，在**文本退化**下
   不成立。适用条件是“质量信号可观测且与标签信息损失相关”；文本当前没有这样的信号。
4. 干净输入上 `lmf_gate_pert` 比 LMF 低 0.020，比拼接低 0.084；如果最终系统
   更看重干净精度，应优先拼接，或把门控加到拼接融合上（下一阶段可做）。

### 3.7 协议敏感性：patience 的影响

- `patience=10` 时 `lmf_gate_pert` 的 best valid 出现在第 13 epoch，
  test Macro-F1 只有 0.5456；放宽到 30 后 best valid 在第 25 epoch 左右，
  test 升到 0.5953（seed 42）。原因是扰动增强让收敛变慢，10 个 epoch 的
  耐心不够。
- 同样 patience 下标准 LMF 的 seed 42 从 0.5831 升到 0.6141，seed 7 从
  0.6101 降到 0.5786；说明 457 条 test 上的 seed/早停波动约 ±0.02，
  单 seed 的小差距不可靠。主表因此使用三个 seed 的均值 ± 标准差。
- 所有对照使用同一 patience / 最大 epoch / 早停指标，未按 test 结果调参。

## 5. 局限与下一步

- **质量门控没有表现出逐样本自适应**：门控值几乎为常数，逐样本最优门控与
  `face_frac` 不相关。当前收益应归因于缺失感知的乘积结构、模态 dropout 和
  受扰训练，而不是“按质量降权”。这是负结果，后续不应在论文/答辩中把它写成
  正向机制。
- 文本质量只有 present 标记；ASR 转写错误下的门控收益需要在接入 ASR 后，
  用 ASR 置信度 / 语言模型分数作为质量输入再检验。当前 15% 汉字替换训练
  没有迁移到 30%，且拉低了干净文本精度，文本扰动训练的配方需要重做。
- 语音白噪声对 Wav2Vec2 特征影响很小（0 dB 下 LMF 只掉 1.8%），
  质量门控没有发挥空间；更接近真实场景的噪声（混响、多人说话、远场）
  可能才会让语音门控有用。
- 扰动强度是固定档位，未做连续强度曲线；当前结论只覆盖表中的档位。
- 457 条 test 上 seed/早停波动约 ±0.02；主表用三个 seed 的均值 ± 标准差，
  但文本缺失等条件方差仍很大（±0.07–0.13），这些条件的结论只能算方向性。
- 拼接 + MLP 在干净、语音、文本、缺失上仍明显更强；如果最终系统更看重
  干净精度，应优先拼接，或把 `present` 掩码/门控加到拼接融合上。
- 自采数据与实时演示阶段仍需验证：摄像头遮挡、麦克风噪声和 ASR 延迟
  在真实设备上的分布与离线扰动并不完全相同。
- 下一步：
  1. 在拼接融合上加入 `present` 掩码和模态 dropout，检验是否能同时保住
     干净精度和缺失鲁棒性；
  2. 接入 ASR 后用置信度/语言模型分数重做文本质量输入；
  3. 在自采数据上复测 `lmf_gate_pert`，记录实时链路的刷新间隔与端到端延迟。
