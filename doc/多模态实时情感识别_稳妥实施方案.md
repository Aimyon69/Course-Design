# 多模态实时情感识别：三模态稳妥实施方案

## 1. 定位与交付

视觉、语音、文本**三路都进入融合模型**，并在实时演示中分别由摄像头、麦克风、语音识别文本提供。目标是在一学期内完成可运行系统、公开数据集上的可复现实验和自采数据测试。任务允许任选两种模态；三模态是本方案主动增加的范围，因此其余环节必须收紧。

| 任务要求 | 本方案交付 |
|---|---|
| 多模态实时情感识别 | 摄像头 + 麦克风 + 实时 ASR 文本，持续输出三类情感极性 |
| 优先中期融合、在现有算法上改进 | 复现三模态 LMF；加入可独立抑制低质量或缺失模态的门控 |
| 公开数据集测试与同类算法对比 | CH-SIMS，同一划分下运行拼接融合、LMF 和改进 LMF |
| 自制数据集测试 | 采集约 40–60 段含人脸、语音和可转写文本的短视频，独立评测 |

## 2. 数据与模型选择

- **公开数据集**：优先 CH-SIMS，按官方训练、验证、测试划分使用；开工第一周确认原始音视频、标注文本、标签和使用许可都能获取。若只能获得预提取特征，先暂停“训练与演示共用同一特征链路”的承诺，确定可复现的特征提取方法后再继续。
- **任务标签**：负面、中性、正面三分类。明确写下连续标签到三类的阈值和中性样本处理方式，之后不根据测试结果改阈值。
- **视觉**：抽样人脸帧，用现成的轻量视觉编码器提取片段特征，先冻结编码器。
- **语音**：Log-Mel + 小型 CNN，训练片段级语音特征。
- **文本**：轻量中文预训练编码器，先冻结大部分层；输入为片段转写文本。
- **实时 ASR**：仅用于把麦克风语音转成文本，不作为第四个训练模型。演示优先选有中文支持、能在实际电脑运行的轻量 ASR 实现；第 7 周前用真实设备验证。

训练和主要公开数据集实验使用 CH-SIMS 人工转写；实时系统使用 ASR 输出。这两种文本来源有分布差异，必须另做一次**测试集 ASR 转写评测**，不能用人工转写的精度代表真实演示精度。

## 3. 核心改进：可退化的质量门控 LMF

先复现标准 LMF，输入三个模态的片段级特征。改进版为每一路计算 `g_m ∈ [0,1]`，输入包括该路质量指标和缺失标记。视觉质量可由人脸可见性/模糊程度估计，语音质量可由语音活动与噪声估计，文本质量至少区分人工转写、ASR 暂缺和 ASR 已确认；不要把 softmax 最大值直接当作可靠度。

门控必须能**分别**减弱三个模态。例如先将每一路 LMF 投影变为 `p_m`，再使用 `p'_m = 1 + g_m × (p_m - 1)` 进入逐模态连乘：`g_m=0` 时该路成为乘法单位元，`g_m=1` 时使用原特征。原始 LMF 的偏置/常数项、输出映射和秩维度按选定论文实现固定。训练时使用模态缺失、音频噪声、人脸遮挡和少量 ASR 转写错误增强，使模型见过质量下降的情况；文本质量输入须在训练时也能计算，不能只在演示时加入一个从未见过的状态码。

**改进主张**：在至少一个模态质量下降时，改进 LMF 的 Macro-F1 下降幅度小于原始 LMF。干净输入的精度提升不预设。代码行数不是成果依据，受控实验才是。

## 4. 实验表格

| 实验 | 配置 | 目的 |
|---|---|---|
| 单模态 | 视觉、语音、文本分别测试 | 证明三路确实参与任务 |
| 算法对比 | 拼接 + MLP、LMF、改进 LMF | 满足同类算法对比 |
| 消融 | LMF、LMF + 扰动训练、LMF + 质量门控、完整方案 | 区分训练增强与结构改进的收益 |
| 鲁棒性 | 干净、固定强度音频噪声、人脸遮挡、文本缺失/ASR 错误 | 验证改进的适用条件 |
| 自采测试 | 相同模型在自采数据上测试 | 满足任务要求并报告域偏移 |
| 实时测量 | 预测刷新间隔、端到端延迟、运行设备 | 说明“实时”的实际表现 |

所有融合方法使用相同训练/测试划分、相同三路编码器和同等训练预算。对照方法如采用扰动训练，改进方法也使用相同扰动。报告 Accuracy、Macro-F1 和混淆矩阵。引用其他论文数字时，只有数据、标签和划分一致才可并排比较；LMF 原论文发表于 CH-SIMS 之前，不能说“对齐原论文的 CH-SIMS 数字”。

## 5. 实时系统

摄像头和麦克风持续采集，音视频特征按时间戳存入短缓冲区。ASR 输出新的部分或已确认文本时，更新文本特征及其时间戳。融合层每约 0.5–1 秒取最近的有效视觉、语音、文本特征；文本尚未到达或过期时带缺失标记继续预测，不阻塞另两路。界面显示人脸画面、转写文本、三类概率、当前预测和实测延迟。

“实时”以实际刷新间隔和采集到显示的延迟验收。ASR 通常需要积累一段语音，不能预先承诺 500 ms 完整三模态结果。CPU 优先跑通；若硬件允许，再启用 GPU。ONNX/INT8 不列为核心交付。

## 6. 自采数据

建议 5–8 人，共 40–60 段，每段约 3–6 秒。每段保留人脸、声音、口头内容及三类标签，并取得知情同意。采集时尽量覆盖三类，记录设备和环境。需要独立检查标签；样本量小时只作外部场景测试和误差分析，不承诺统计显著提升。

## 7. 12 周安排和范围控制

| 周次 | 必须完成 |
|---|---|
| 1 | 核查 CH-SIMS 原始数据与文本可用性；确认机器上可用的 ASR；预约自采被试 |
| 2–3 | 统一数据接口和三路特征提取；完成单模态结果 |
| 4–5 | 拼接基线与 LMF 复现 |
| 6–7 | 质量门控、扰动训练、消融和 ASR 转写测试 |
| 8–9 | 三路实时采集、缓冲与界面；同步自采数据 |
| 10 | 自采测试与实测延迟 |
| 11–12 | 检查可复现性、整理表格和答辩材料 |

**不做**：复现 MulT/MISA、多个公开数据集、知识蒸馏、结构化剪枝、INT8 必做、边缘设备部署、超过 60 段自采数据。若数据或 ASR 获取在第 1 周失败，先解决依赖，不把同一评测任务临时换成难以比较的数据。

## 8. 完成判断

最低交付线是：三模态实时演示能持续运行；公开数据集有单模态、融合基线、改进方法和消融结果；自采数据完成独立测试；提供模型、代码、数据划分和实测延迟记录。质量感知方法在受干扰测试中是否“明显改进”由结果决定，不能预填 3–5 个百分点。三模态方案的工作量仍偏紧，稳定交差依赖于冻结骨干、少量可靠对照和及早验证数据/ASR 两个前置条件。
